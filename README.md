# Gooclaim OS documentation

The public documentation site for Gooclaim OS, built with [Mintlify](https://mintlify.com).

- Pages are `.mdx` files; the navigation is in `docs.json`.
- Every push to `main` is published at once. Push only finished pages that are safe for
  anyone to read.
- Every statement on a page must be true of the product as it runs today.

Preview locally:

```bash
npm i -g mint
mint dev
```
